## README (extracto literal)

> Uses [Gherkin](https://github.com/cucumber/gherkin-javascript) to parse feature files and runs linting against the default rules, and the optional rules you specified in your `.gplintrc` file.
>
> Forked from [gherkin-lint](https://github.com/vsiakka/gherkin-lint)
>
> Access to the documentation site to know how to use GPLint: https://gplint.github.io/

Quickstart: `npm install --save-dev gplint`; crear `.gplintrc` (JSON, con comentarios admitidos), con reglas como `"no-unnamed-features": "error"` o `["error", { …opciones }]`; ejecutar `gplint tests/features`.

## CLI (`gplint --help`, 2.6.2)

```
gplint [options] <feature-files>
  -c, --config         Configuration file  [default: ".gplintrc"]
      --fix            Automatically fix problems
  -f, --format         Output format. [choices: "json", "stylish", "xunit"] [default: "stylish"]
  -i, --ignore         Comma seperated list of files/glob patterns that the linter should ignore, overrides .gplintignore file
      --maxWarnings    Number of warnings to trigger nonzero exit code [default: -1]
  -R, --ruleOverwrite  Overwrite the configuration of a rule. Format: <rule-name>=<rule-config>
  -r, --rulesdir       Additional rule directories.
```

## CHANGELOG (extracto literal de la 2.0.0)

> ### 💥 Breaking Change
> * This package is now pure ESM. It should not affect if using gplint as a cli tool, if you have problems with integration, please, first [read this](https://gist.github.com/sindresorhus/a39789f98801d908bbc7ff3ecc99d99c).
> * Drop Node 14 and 16 support.
> * Level "on" was deprecated on v1, and now was removed. Replace it with "error" or "warn" on your .gplintrc file.
> * On rule `required-tags` the `tags` was deprecated, now was removed. Replace it with `scenario` the use in the same way.

Versiones 1.x (resumen del CHANGELOG): la 1.0 añadió los niveles `warn`/`error` (`on` se asumía `error`) y `--max-warnings`; la 2.1.0, el autofix (`--fix`); la 2.3.0, la regla `max-keywords` y mejoras del autofix.
